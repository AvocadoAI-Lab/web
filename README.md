# Avocado.ai Public Portal

Bilingual, evidence-driven public portal for Avocado.ai and SenseL.

## Run locally

```bash
npm ci
npm run check
npm run build
npm run start
```

Open `http://localhost:3000/zh-Hant` or `http://localhost:3000/en`.

The public site contains no customer telemetry or authenticated routes. Contact, booking, and customer-login destinations are environment-controlled and remain disabled or routed to contact until approved.
